# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability.

Instead, use GitHub's private vulnerability reporting for this repository:
[Security → Advisories → Report a vulnerability](https://github.com/kajisho5/image-skill/security/advisories/new).
This lets maintainers review and fix the issue privately before it's
disclosed publicly.

## Supported Versions

This project is pre-1.0. Only the latest published release receives fixes;
please update before reporting an issue that may already be resolved.
